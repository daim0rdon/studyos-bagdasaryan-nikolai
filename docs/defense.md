### 1. Запуск

Откройте терминал в папке проекта и выполните `python main.py`. При первом запуске придумайте пароль администратора (не менее 6 символов); пароль вводится невидимо. После входа приглашение будет похоже на `admin@studyos:/home/admin$`.

### 2. Дерево каталогов и файлы

```text
whoami
pwd
mkdir demo
mkdir demo/docs
touch demo/docs/notes.txt
write demo/docs/notes.txt "Привет из StudyOS"
cat demo/docs/notes.txt
tree
ls demo/docs
copy demo/docs demo/copy
move demo/copy demo/backup
rename demo/backup archive
tree demo
```

Объяснение: SQLite хранит каждый объект отдельно, у него есть полный путь и ID родителя. Поэтому вложенные папки, копирование и перемещение работают как с деревом.

### 3. Процессы и память

```text
mem
run editor 64
ps
mem
```

Посмотрите ID запущенного процесса в `ps` и завершите его командой `kill <PID>` (например, `kill 1` при новом запуске). Снова выполните `mem`. Выделенная память освободится.

### 4. Права доступа

```text
register student
logout
login student
whoami
touch /home/admin/secret.txt
mkdir myfolder
tree
logs
```

При `register student` и `login student` программа отдельно запрашивает пароль. Команда создания файла в `/home/admin` должна вернуть сообщение о запрете. В `logs` появится `DENIED`. В личном каталоге `student` создание папки будет разрешено.

### 5. Журнал и статистика

```text
report
logs
```

Покажите количество файлов/каталогов, объём текста и последние операции. У `admin` журнал охватывает систему, у `student` — только собственные вызовы.

### 6. Тесты

В другом терминале, находясь в корне проекта:

```bash
python -m tests.test_fs
python -m unittest discover -s tests -v
```

Ожидаемый результат: `OK`; **20 тестов** основной файловой системы, **33 теста** суммарно.

## Возможные вопросы преподавателя

**Это настоящая ОС?** Нет, учебная имитация механизмов ОС согласно ТЗ. Приложение не заменяет Windows/Linux и не управляет реальными процессами.

**Зачем `parent_id`?** Чтобы хранить дерево: объект ссылается на папку-родителя. Корень `/` не имеет родителя (`NULL`).

**Чем `copy` отличается от `move`?** `copy` создаёт независимые объекты с новыми ID, а `move` сохраняет их ID, меняя расположение и пути.

**Где хранятся данные?** В `studyos.db` (SQLite); база создаётся при первом запуске и сохраняется между сессиями.

**Как реализованы права?** По роли и `owner_id`. Администратор имеет расширенные права; пользователь работает со своим поддеревом `/home/<login>` и своими процессами.

**Почему SHA-256?** Потому что это прямо указано в учебном ТЗ. В промышленном приложении лучше применять алгоритм для паролей (например, Argon2id).

**Что означает `DENIED`?** Системный вызов отклонён проверкой прав, и причина фиксируется в журнале.

**Как проверялась корректность?** Набором автоматических тестов `unittest`, включая проверки файловой системы и отказов в доступе.
